Move my old artworks to the server

Your first artworks were saved inside the browser where you uploaded them, so other laptops could not see them. This page copies them to the shared server. Do this once.

  1. Open this page in the same browser, on the same laptop, opened the same way as the old gallery (for example, double-click this file if you used to double-click index.html).
  2. Make sure the server is running (node server.js).
  3. Fill in the form below and press the button.
